# Student results: GPU track (start here)

Everything about the GPU-track student grid in one place: what was run, what came out, and every table
and figure, each regenerated by a script from stored outputs. Nothing here is edited by hand.

- **Grid:** 13 arms × 5 seeds = 65 runs, trunk M, 401 unlabelled nights (HMC 151, CinC 2018 250).
  Run folders: `../runs/student/<run>/` (outside the repo).
- **Freeze:** every run at decoder D0, τ 0.5, no snapping (amendment 10, commit `784ada7a`). Headline arm:
  `student_rules4_fixA_gpu` (noise tables anchored at the Dawid–Skene matrices, λ 0).
- **Gold sets, scored once** (commit `e0bc7816`): DREAMS expert 1, N2, onset ±0.5 s, first 1000 s, pooled F1;
  NAP `nap_points.v1` integrated F1 (centre tolerance 0.25–1.5 s, N2, C3, 30 naps, 17 people).
- **Plan and hypotheses:** `notes/plans/student_architecture.md` (H1–H5, section 1; statistics, section 8.6).
  Technical specification: `docs/student_architecture.md`.

## The results in eight lines

1. Headline student: **DREAMS F1 0.743** (seeds 0.727–0.754), **NAP integrated F1 0.419** (0.410–0.425).
2. It beats every rule teacher and SUMOv2 on DREAMS (SUMOv2 0.693), and is above A7 on all 8 excerpts.
   Expert 2 scored against expert 1 under the same rule reaches 0.70.
3. **H1** (beats its best teacher): yes on DREAMS (+0.074, p 0.0078), no on NAP (ties Wonambi UCSD).
4. **H2** (beats the teachers' majority vote): **not supported** (+0.018 DREAMS, −0.009 NAP, both inside noise).
5. **H3** (noise model beats a plain student on soft targets): supported (+0.083 DREAMS, +0.032 NAP), but
   plain students on vote or Dawid–Skene targets reach 0.715–0.724, so the real gain is about +0.02.
6. **H5** (matches SUMOv2 within ±0.02): equal or better on both sets (DREAMS +0.050, P(student better) 0.84;
   NAP +0.045, CI excludes 0).
7. **H4** (uncertainty tracks expert disagreement): AUROC 0.64, misses the pre-registered 0.7. The mean
   probability alone reaches 0.76.
8. The free noise model collapses into over-detection; anchoring at Dawid–Skene is what makes it work.
   Agreement with the vote on validation nights predicts DREAMS rank (ρ 0.79), not NAP (0.36).

Full tables and every test: [`report.md`](report.md).

## Regenerate

From the repo root, root environment, in this order (CPU only; no training):

```bash
uv run python experiments/student/report.py
uv run python experiments/student/report_figures.py
```

## Known caveats

- DREAMS has 8 excerpts: the smallest two-sided Wilcoxon p is 0.0078; most DREAMS contrasts overlap zero.
- The ablations were run against the free noise model (λ 0.01), not the headline, so they do not
  decompose the headline arm.
- `consensus_ds_corpus` scores exactly like the majority vote (left out of the figures); not yet explained.
- In one secondary NAP contrast (free noise model vs soft targets) the pooled score and the per-person
  count point in opposite directions; a few people with many marks dominate the pooled score.
